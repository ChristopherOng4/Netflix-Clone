# Netflix Clone 🎬

This is a full-stack clone of Netflix, built using the MERN stack (MongoDB, Express, React, Node.js). It includes a responsive frontend, secure backend API, and user authentication.

## 🔥 Features

- ✅ User Authentication (Login/Register)
- 🎥 Movie and Series browsing UI
- ⭐ Add to favorites / watchlist
- 🔒 JWT-based session management
- 📦 RESTful API using Express
- 🌐 Frontend built with React
- 🛠️ MongoDB for data storage

## 🖥️ Tech Stack

**Frontend**:
- React
- Axios
- React Router

**Backend**:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT (JSON Web Tokens)
